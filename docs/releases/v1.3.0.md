## 偶鲸鲸 v1.3.0

### 本次更新

- 新增 DeepSeek 流式文字对话，支持取消、手动重试和近期六轮上下文；会话在内存中保存，收起后清空。
- 半透明对话气泡默认覆盖桌宠下半身；输入区右侧双向箭头可展开至全身，窗口始终限制在桌宠范围内。
- 对话打开时暂停自动散步，收起后恢复；支持拖动角色或气泡标题，窗口跟随移动和缩放。
- API Key 与模型配置移入设置，Key 由 Windows 当前用户加密保护，可在设置中移除。
- 天气、番茄钟和待办整合进同一个对话区域，使用明确的本地指令执行，无需大模型 Key。
- 收起气泡后计时继续；到点播放提示音并自动唤起紧凑气泡，保留至手动收起。

### 启动与使用

下载并解压 `DeepSeekPet-win-x64-v1.3.0.zip`，保留文件夹中的全部文件，双击 `DeepSeekPet.exe`。这是 Windows x64 独立包，无需另装 .NET；升级前先退出旧桌宠。

右键桌宠 → 设置，填写 DeepSeek API Key 和模型。双击桌宠打开对话；Enter 发送，Shift+Enter 换行。

输入 `帮助` 查看本地功能，也可直接尝试：

- `上海天气`
- `开始专注25分钟`、`暂停计时`、`继续计时`、`剩余时间`
- `添加待办 买牛奶`、`查看待办`、`完成待办1`

### 验证与范围

已通过编译、本地模拟接口检查，以及 150/250/420 三档窗口边界、输入布局、散步暂停、隐藏后计时和到点唤起检查。真实 DeepSeek 联网与天气查询需在使用者本机验收。

普通对话会将问题与近期上下文发送至 DeepSeek。待办与计时在本机处理；天气查询提交城市至 Open-Meteo。聊天记录不落盘，待办与时长设置保存在本机。程序退出后计时停止，重启不恢复未完成计时。

本版未包含任意自然语言工具调度、周期任务、截图问答或笔记 RAG。小尺寸桌宠的消息显示空间有限，可展开后滚动阅读。
