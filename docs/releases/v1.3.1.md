## 偶鲸鲸 v1.3.1

### 更新

- 新增枫原万叶透明 Q 版皮肤，在设置 → 角色中选择。
- 新增桌宠右键跳舞入口：原地上下压缩与拉伸，不打开额外窗口；跳舞期间暂停散步。
- 动作从原形开始并回到原形，跨周期速度连续，改善最高点停顿感。
- 本发行包附带用户指定 B 站视频 BV1kFar6KE4t 的开头 3 分 05 秒音频，支持本地循环播放。
- 修正单文件发布时音频资源的外置规则。

### 使用

下载并完整解压 `DeepSeekPet-win-x64-v1.3.1.zip`，双击 `DeepSeekPet.exe`。Windows x64 自包含版，无需另装 .NET。保留 `Assets` 文件夹，升级前先退出旧桌宠。

右键 → 设置 → 枫原万叶 → 保存，切换新皮肤。右键 → 跳舞 · 朋友的酒 DJ 开始播放，再次点击停止。

附带 `.sha256` 校验文件。已验证解压启动、音频播放与循环，以及现有功能回归。程序未签名。

### 素材与源码

音频来自用户本地缓存，未纳入 Git 源码；源码构建需自行提供 `Assets/Audio/friends-wine-bilibili.m4a`。音乐及万叶角色相关权利归各自权利人，仓库代码许可证不授予相关素材的权利。

此包以 `7af884a` 为源码基线，包含本版音频外置打包修正；不含工作区中未提交的聊天界面改动。
