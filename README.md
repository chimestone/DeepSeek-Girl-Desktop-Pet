# DeepSeek 娘桌宠

一个 Windows 桌宠程序，可选接入 DeepSeek 云端对话。角色会待机呼吸、偶尔散步，并在单击时给出 Q 弹回应。

内置 DeepSeek 娘、咕咕嘎嘎、菲比、啥子龙、睦子米和 Claude 娘六个角色，采用统一的简约 Q 版画风。Claude 娘为暖陶土色系原创角色，并非官方形象。

## 操作

- 左键拖动：移动桌宠
- 左键单击：Q 弹互动
- 左键双击：显示或隐藏与桌宠同比缩放的半透明助手气泡
- 右键：打开设置、切换自动散步或退出
- 右键 → **跳舞 · 朋友的酒 DJ**：直接播放音乐并原地上下弹动，再次点击停止。
- 设置顶部：通过角色预览卡片切换桌宠，切换时使用短暂交叉淡入淡出
- 设置中还可调整自动散步、速度、大小、置顶、边缘吸附和开机启动
- 轻量对话：天气、番茄钟和待办在同一消息区使用；对话打开时暂停自动散步，仍可手动拖动。默认采用 RPG 对话框，只显示桌宠最新一次回复；等待时保留上一条，新回复开始后替换。输入框右侧 ⤢ 展开至桌宠全身范围并显示双方当前会话历史，⤡ 收回至下半身并只显示最新回复；两种尺寸均不超出桌宠窗口。

程序不读取 DeepSeek 网页账号，不显示余额。设置与待办保存在本机；主动查询天气访问 Open-Meteo，主动发送对话访问 DeepSeek。

## 跳舞模式

右键 → **跳舞 · 朋友的酒 DJ**，桌宠直接原地上下弹簧伸缩，不打开额外窗口，不左右晃动、不旋转；向上回弹时收窄拉伸，向下压缩时稍微变胖，按 130 BPM 基准节拍与低音能量混合驱动。跳舞期间停止自动散步；再次点击 **停止跳舞** 停止音乐并恢复原来的行为设置。保留手动拖动和换肤。

默认播放 [DJ95：朋友的酒（DJ阿帆 Electro Rmx 2020）公开试听](https://www.dj95.com/mp3/121445.html)。首次加载需要联网，加载期间先开始上下弹动；缓存位于 `%APPDATA%\DeepSeekPet\DanceCache`。失败时停止跳舞，右键菜单显示重试提示；音乐播放结束自动恢复待机。发布包不包含歌曲文件。

播放音频中的 20–150 Hz 低频只在每拍开始时确定动作力度，持续低音不会阻止回弹；未采集麦克风或系统音频。130 BPM 是设定值，未自动测量歌曲 BPM 或底鼓相位。每拍以原始形状（相对位移为零、缩放为 1）为起讫点：130 BPM 下约 90 ms 下压、170 ms 拉伸，剩余约 202 ms 回到原形，没有拍尾等待。采用三次 Hermite 曲线，位置和速度连续；最高点自然转向，回到原形时以相同速度接入下一拍，不在最高点重启动画。高潮模式与力度在拍首锁定，下一拍再更新。常态 Y 范围 0.78–1.08、X 范围 0.94–1.18；高潮 Y 范围 0.55–1.15、X 范围 0.88–1.35。范围是限幅边界，并不表示每拍都会达到全部极值；倍率按给定视觉规范实现，不严格保持面积。调参位于 `DanceMotion.cs`（阶段时长、平滑曲线、上下幅度）和 `DanceAudio.cs`（频段、能量增益）。

## 开发构建

需要 Windows 和 .NET 9 SDK：

```powershell
dotnet build .\DeepSeekPet.sln -c Release
dotnet publish .\src\DeepSeekPet\DeepSeekPet.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

发布文件位于 `src\DeepSeekPet\bin\Release\net9.0-windows\win-x64\publish\`。


## DeepSeek 对话

对话框覆盖桌宠身体，打开时不自动显示欢迎语、输入用法或思考提示。底部保持简单输入框与发送、取消及展开按钮；回复区用于显示实际回答。错误反馈、运行中的计时状态和到点提醒仍保留。

右键桌宠 → 设置，在“大模型对话”中保存 API Key 和模型名称；双击桌宠打开对话，输入问题，按 Enter 或点击 ↑ 发送，Shift+Enter 换行，■ 取消回复。默认模型为 `deepseek-flash`，使用非思考模式；模型可以自行修改。不要把 Key 发给协作者或写入仓库。

- 回复逐段显示，支持取消；失败时保留输入，用户手动重试，不自动重发计费请求。
- 仅完整成功的对话进入上下文。近期上下文最多六轮、24000 个字符，超出时按整轮移除最早记录；字符限制并非精确 token 或费用预算。
- 单次输入最多 8000 字符，回复最多 2048 tokens，调用最多等待三分钟。取消只能停止本机等待，不能保证服务端停止计算或免除费用。
- 会话只在内存中保存；收起气泡或点击顶部 ＋ 都会清空上下文，聊天记录不写入磁盘。发送时，问题和保留的上下文提交给 DeepSeek。
- Key 通过 Windows DPAPI 当前用户加密后保存在 `%APPDATA%\DeepSeekPet\chat.json`，不写日志。换 Windows 用户或迁移机器需重新输入 Key；删除该文件可移除配置。
- 配置仅在设置里展示，可勾选移除已保存的 Key。气泡顶部 ⚙ 也可打开设置，拖动顶部标题可移动桌宠；默认紧凑窗口覆盖下半身，展开覆盖全身，没有外侧窗口或阴影。
- 本地指令：`上海天气`、`查询天气 北京`、`开始专注25分钟`、`休息5分钟`、`暂停计时`、`继续计时`、`重置计时`、`剩余时间`、`添加待办 买牛奶`、`查看待办`、`完成待办1`、`删除待办1`、`清除已完成待办`。输入 `帮助` 可查看用法。
- 本地能力按上述明确指令识别，不依赖大模型；其他问题进入云端问答。未实现任意自然语言工具调度或外部 skill 插件。待办与计时指令、执行结果不加入云端会话；天气仅提交城市给 Open-Meteo。
- 待办、上次天气城市和专注/休息时长自动保存。收起、展开或新会话均不停止计时；到点播放提示音并自动打开紧凑气泡，保留至手动收起。使用截止时间避免计时因界面关闭或电脑休眠而停止推进。
- 程序退出后不再运行计时，重启不恢复正在进行的计时；指定时间提醒和周期任务不在这一版范围内。

真实验收：发送“记住我的代号是蓝鲸”，再问“我的代号是什么”；收起后重新打开再问，确认不恢复旧上下文。发送长回答时点击取消，确认仍可再次发送。错误 Key 应显示配置错误。尚未包含图片输入、RAG 或工具调用。

## 调用层检查

```powershell
dotnet run --project .\tests\DeepSeekPet.ChatChecks -c Release
```

检查使用本地模拟 HTTP，不访问云端、不使用真实 Key；覆盖流式解析与会话边界、本地指令识别、150/250/420 三档紧凑与展开布局、散步暂停、收起后保留计时和到点唤起。界面检查会短暂创建测试窗口，不改写本机待办或配置。

成员 B 可复用 `DeepSeekChatSession.SendAsync(key, model, prompt, onText, cancellationToken)` 接收文本增量；任务完成、取消和失败分别通过 Task 完成、取消异常和异常表示。`Clear()` 清空会话；调用层不依赖窗口。`ChatConfiguration` 负责本机配置与 Key 保护。

官方接口参考：[Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)、[模型名称](https://api-docs.deepseek.com/api/responses)。
